# 天玄修仙录 · 本地修仙模拟器

> 作者：**babyQ**
> 单人 · 月令回合制 · 开放世界修仙模拟器（纯本地运行，数据不出本机）

《天玄修仙录》是一款运行在你自己电脑上的文字修仙游戏。你从一介凡人起步，
测灵根、觉醒道韵、闯荡秘境、结识道友，在一次次月令流转中问道长生。
全部存档以明文 `.ini` 形式保存在本地，可随时手动查看与修改，不上传任何服务器。

> **关于本分享版**：本包**不含任何存档**，是纯游戏本体。收包人首次双击 `start.vbs` 启动时，
> 会在 `存档/` 文件夹自动生成一个全新的空存档，直接开局即可，无需额外准备。

---

## 一、一句话上手

解压 → 双击 `start.vbs` → 浏览器自动打开就能玩 → 不玩了双击 `stop.bat` 关掉服务器。

## 二、如何启动（启动教程）

### 环境要求
- 需要 **Node.js 18 及以上版本**（系统需能执行 `node` 命令）。
- 本游戏**零第三方依赖**，无需 `npm install`。
- 若本机还没装 Node.js：到 https://nodejs.org 下载 **LTS** 版安装即可，脚本会自动找到它。

### 日常启动（推荐：无窗口）
1. 双击 **`start.vbs`**。
   - 它在后台静默启动服务器，**不弹出任何黑色命令行窗口**。
   - 约 2 秒后自动打开你的默认浏览器，进入游戏。
2. 浏览器访问 **http://127.0.0.1:8613** 即可游玩。
3. 如果服务器已经在跑（比如你又双击了一次），脚本只会再开一个浏览器页面，不会重复启动。

### 备选启动（可见窗口）
- 双击 **`start.bat`** 也可启动，与 `start.vbs` 效果相同，只是会短暂显示一个命令行窗口。

### 关闭游戏
- 双击 **`stop.bat`** 即可静默关闭服务器（无弹窗、无提示），释放端口与资源。
- 直接关掉浏览器页面不会关闭服务器，`stop.bat` 才是「关机键」。

### 换电脑 / 迁移
- 整个游戏文件夹直接复制走即可。带上 `存档/` 文件夹，进度就不丢。
- 分享给别人的**无存档版**首次启动会自动建一个空存档，对方是从头开局；若想连同你的进度一起给，把 `存档/` 文件夹也一并复制过去即可。
- 到新电脑后先装好 Node.js（加入 PATH），再双击 `start.vbs`。

> 端口说明：默认 `8613`。若该端口被占用，服务器会自动尝试 `8614`、`8615`……依次递增，
> 此时请以浏览器实际打开的地址为准。

## 三、核心玩法

### 1. 角色创建
- **灵根**：决定修炼速度与属性偏向。开局随机生成品级（如「中品」）与五行元素（火 / 土 / 金……），并附带修炼速度倍率。
- **道韵**：修仙机缘所钟。开局可能「未觉醒」，在后续游历机缘中觉醒，觉醒后提供额外战力与特效。
- **修为与境界**：通过修炼、丹药、机缘提升，跨越练气、筑基、结丹、元婴、化神……直至飞升。

### 2. 月令回合制
游戏以「月」为时间单位推进。每回合你可安排行动（修炼、游历、炼丹、经营、社交等），
岁月流转带来年龄、寿元、人脉与机遇的变化。合理安排节奏，方能在大限之前叩问长生。

### 3. 战斗与战力平衡
- 战力由修为境界、灵根加成、装备、法宝、功法、灵兽、道韵、丹药等多部分综合而成。
- 遭遇的妖兽 / 修士敌人战力**随你的当前战力动态缩放**：普通敌人可稳定刷练级，
  强敌则构成真实挑战、需要更好的装备与策略；切磋道友也大致势均力敌。
- 战斗结果以胜率估算 + 回合结算呈现，胜负皆可推进剧情。
- **伤势系统**：战斗失败会留下伤势（以「月」计），伤势越重胜率越低（每月约 -3%，最多 -15%），
  用「疗伤丹」可消除伤势。

### 4. 行囊与储物
- 行囊开局默认 **100 格**，足够存放前期资源。
- 容量不足会限制资源获取；可在坊市购买 **「储物袋扩容契」**（+20 格）进行扩容，
  也可通过材料打造提升储物袋品级（不同途径 +15~+20 格）。
- 装备/法宝拆下后进入「备用」区，可点「↩ 返回行囊」放回。

### 5. 功法
- 功法可在坊市、战斗缴获、天命奖励、拍卖等途径获得，自动收录进图鉴。
- 行囊面板有独立的「功法」区块，可查看品级、层数、战力，并「设为主修」。
- 主修功法会在战斗中提供战力加成。

### 6. 道缘（道友系统）
- 道友**不会在开局全部出现**，而是随着游戏进程、游历与机缘**逐个结识解锁**。
- 选择存档 / 仙缘界面只展示已结识的道友；未结缘者以「待缘」计数提示，等待你在剧情中相逢。

### 7. 灵兽
- 灵兽栏在侧边栏。收服灵兽需要前往**栖息地**（游历中解锁，通常需栖息地等级 5 以上）。
- 提高收服成功率可用「驭兽香 / 驯兽口粮」，或寻找「驯兽师」道友相助。
- 灵兽可在战斗中助战，并提供战力加成，契约还能解锁更多栏位。

### 8. 其它系统
- **图鉴**：记录已遭遇的妖兽、物品、道友、功法等，可在「仙缘·太初之气」等条目查看来源与效果。
- **宗门 / 丹道 / 坊市**：随进度逐步解锁养成。
- **多存档槽**：支持 1、2、3…… 多个独立存档，互不影响。

## 四、头像

游戏内置多款本地头像（SVG，无需联网、绝不会出现 404 / 破损）。
角色创建或设置中可选其一；选择存档界面也会直接显示该存档对应的内置头像。
（自定义上传头像为可选扩展，未配置时自动回退到内置头像。）

## 五、存档说明

- 所有存档位于游戏目录下的 **`存档/`** 文件夹。
- 每个存档槽对应一个子目录（如 `存档/1/`、`存档/2/`），内部为一组**中文命名、明文可读**的 `.ini` 文件：
  `个人信息.ini`、`属性.ini`、`货币.ini`、`装备.ini`、`道缘.ini`、`图鉴.ini`…… 等。
- 你可以直接用记事本打开这些文件查看或微调数值；修改后于游戏内「存档 / 读取」即可生效。
- 旧版本散落在 `存档/` 根目录的 `.ini` 会在首次启动时自动迁入 `存档/1/`。

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 双击脚本提示「未找到 Node.js」 | 安装 Node.js 并加入 PATH，或把 `node.exe` 放到脚本可识别的路径 |
| 浏览器打不开 / 白屏 | 确认服务器已启动（端口 8613 被监听）且无报错；以实际地址访问 |
| 双击 `start.vbs` 没反应 | 多半是没装 Node.js；先安装后再试，或改用 `start.bat` 看报错 |
| 想清空某存档重开 | 游戏内「设置 → 转世重修 / 清空存档」，或删除对应 `存档/<槽>/` 目录 |
| 想迁移到其它电脑 | 直接复制整个游戏文件夹即可；`存档/` 一并带走则进度不丢 |
| 头像不显示 | 刷新页面；内置头像为本地资源，正常不会缺失 |

## 八、目录结构

```
天玄修仙录/
├─ README.md          # 本说明（玩法 + 启动教程）
├─ start.vbs          # 一键启动（隐藏窗口，推荐双击）
├─ start.bat          # 一键启动（可见命令行窗口的备选）
├─ stop.bat           # 一键关闭服务器（无弹窗）
├─ server.js          # 零依赖本地服务器（运行必需，勿移动）
├─ public/            # 前端资源（HTML / CSS / JS，运行必需，勿移动）
├─ 存档/              # 玩家存档（明文 ini，随游玩自动生成）
└─ tests/             # 开发 / 测试脚本（非游玩必需，已归类到此文件夹）
```

> 说明：`server.js`、`public/`、`存档/` 三者由服务器按固定相对位置加载，
> 请保持它们在根目录，不要单独移动，否则游戏将无法启动。

## 九、技术说明

- 前端：原生 HTML / CSS / ES Modules，**无构建步骤**。
- 后端：Node.js 内置 `http` 模块，**零第三方依赖**。
- 数据：客户端计算 + 服务端明文 `.ini` 持久化，便于阅读与二次创作。
- 通信：通过 `/api/info`、`/api/slots`、`/api/save` 等本地接口读写。
